# SNM-Driven-Sizing-Optimization-in-IGZO-Based-6T-SRAM-Design
Investigated how transistor sizing affects SRAM stability by designing and simulating a 6T SRAM cell in both conventional bulk-Si and IGZO thin-film transistors, comparing HSNM/RSNM/WSNM across six sizing configurations in Cadence Virtuoso and validating theoretical predictions against simulated results.
